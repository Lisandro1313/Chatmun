# Guía de Configuración - IA Inteligente

Tu asistente municipal ahora puede usar diferentes tipos de inteligencia artificial. Aquí te explico las opciones:

## 🧠 Opciones de IA Disponibles

### 1. Respuestas Inteligentes (Gratis - Recomendado)

- ✅ **Gratis y sin configuración**
- ✅ **Funciona inmediatamente**
- ✅ **Respuestas muy inteligentes y contextuales**
- ✅ **Especializado en tareas municipales**
- 🔧 **Configuración**: Ninguna, ya está funcionando

### 2. OpenAI GPT-3.5 (Pago - Muy Avanzado)

- 🚀 **Conversaciones muy naturales**
- 🚀 **Comprensión excelente del contexto**
- 💰 **Requiere pago** (~$0.002 por 1000 palabras)
- 🔧 **Configuración**:
  1. Crear cuenta en [platform.openai.com](https://platform.openai.com)
  2. Generar API key
  3. Configurar en la aplicación

### 3. Ollama Local (Gratis - Instalación Requerida)

- ✅ **Completamente gratis**
- ✅ **Funciona sin internet**
- ✅ **Privacidad total**
- ⚙️ **Requiere instalación**
- 🔧 **Configuración**:
  1. Descargar [Ollama](https://ollama.ai)
  2. Instalar en tu PC
  3. Ejecutar: `ollama run llama2`
  4. Mantener ejecutándose

## 🎯 ¿Cuál elegir?

- **Para empezar inmediatamente**: Respuestas Inteligentes
- **Para máxima calidad**: OpenAI (si puedes pagar)
- **Para uso privado/gratis**: Ollama (si puedes instalar)

## 🔧 Cómo cambiar la configuración

1. Haz clic en "Configurar IA" en la esquina superior derecha del chat
2. Selecciona tu opción preferida
3. Si eliges OpenAI, ingresa tu API key
4. ¡Guarda y disfruta de tu IA inteligente!

---

**Nota**: Las respuestas inteligentes incluidas son muy avanzadas y específicas para trabajo municipal. ¡Pruébalas primero!
